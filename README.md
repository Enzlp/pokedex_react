# Pokedex App Implementation 

Implementación de una aplicación web que emula una pokedex en React, usando el framework de NextJS y la API pública "PokéAPI".

## How to run

Para poder correr la app, es necesario descargar una copia de este repositorio, luego dentro del directorio pokedex instalar los paquetes correspondientes con:

``` Terminal
npm install
```

Luego, para poder usar la aplicación, usar el entorno de desarrollo de NextJs con:

``` Terminal
npm run dev
```
